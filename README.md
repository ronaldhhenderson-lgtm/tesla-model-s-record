# Tesla Model S VY1428 — Vehicle Archive 車輛檔案

Long-term maintenance archive compiled from 18 pages of original service invoices (Aug 2026).
長期維修檔案，2026-08 由 18 頁原廠工單掃描正本編製。

**Open the archive → `index.html` (or the GitHub Pages URL of this repo).**

| File | Content |
|---|---|

| `maintenance-record.html` | Maintenance & service record 維修保養總紀錄 (繁中/EN) |
