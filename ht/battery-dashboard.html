點解睇「推算滿電續航」而唔係 SOC？ Fleet API 唔會直接俾電池容量。呢個數字 = 剩餘續航 ÷ 可用電量 × 100， 即係將任何電量狀態換算成「如果充到 100% 會有幾遠」。只取電量 ≥ 50% 嘅樣本，因為低電量時 BMS 估算誤差較大。 呢個係趨勢指標，唔係實驗室容量測試 —— 睇斜率，唔好執著單日數字。

DC-DC output		 ✓ 13.8–14.6 V（補電中） ✕ 持續 < 13.5 或 > 15.0 — 轉換器異常
誠實聲明 — 以上界線係業界／車主社群長期使用嘅經驗值，我搵唔到 Tesla 官方公開規格文件，所以唔會扮成官方數字。 用法：睇你自己嘅趨勢比睇絕對值有用得多 —— 同一部車、同一測量條件下，壓差由 30 mV 升到 70 mV， 比「70 mV 係咪合格」更有意義。

測量條件會大幅影響讀數：啱啱充完電或者啱啱大力加速完，壓差會暫時偏高；電量極低時亦然。 為咗可比較，建議固定喺 SOC 40–70%、靜置 20 分鐘以上先讀數，每季都用同一個條件。
